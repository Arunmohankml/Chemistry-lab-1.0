A browser-based virtual chemistry lab simulator built for Kerala syllabus higher secondary students to practice salt analysis experiments before practical exams.

This project recreates common chemistry lab procedures digitally, allowing students to perform reactions, observe precipitates, simulate flame tests, identify ions, and revise practical chemistry in an interactive way.

## Features

- Interactive virtual lab environment
- Drag-and-drop salt analysis simulation
- Cation and anion identification tests
- Flame test color simulation
- Gas evolution and precipitate visualization
- Exam mode with randomized salts
- Mobile-friendly touch controls
- Reset and undo options
- No backend required

## Purpose

Chemistry Lab 1.0 is made mainly for Kerala syllabus students who want to revise and practice practical chemistry before their lab exams.

It helps students understand:

- Which reagent to add
- What reaction happens
- What observation appears
- How to identify cations and anions
- How salt analysis works in practical exams
